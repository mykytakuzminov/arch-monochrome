# 🚀 Arch Onyx Dotfiles

Personal monochrome Arch Linux dotfiles

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

</div>

---

## Features

- **Hyprland** - tiling Wayland compositor as the window manager
- **Alacritty** - GPU-accelerated terminal emulator
- **Neovim** - configured as the primary editor
- **Starship** - minimal, customizable shell prompt
- **install.sh** - script to install dotfiles

## Getting Started

### Installation

```bash
git clone https://github.com/mykytakuzminov/arch-onyx-dotfiles.git
cd arch-onyx-dotfiles
chmod +x install.sh
./install.sh
reboot
```
